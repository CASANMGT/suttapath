# SuttaPath — a beginner's guide to the Pali Canon

A study app that takes a complete beginner, English-speaking, adult, from "what is the Pali Canon?" to reading early Buddhist suttas with comprehension and applying them to ordinary decisions about work, money, friendship, and integrity.

Built as an installable web PWA. Content from SuttaCentral (CC0). One guided path of 36 sessions, not a library.
